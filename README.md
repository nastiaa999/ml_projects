# 🚀 Проекты

## 🛒 Анализ транзакционных данных. Поиск ассоциативных правил и выявление скрытых структур в данных

**Описание**

Проект посвящён анализу транзакционных данных с целью поиска часто встречающихся товарных наборов, построения ассоциативных правил и выявления скрытых закономерностей с помощью методов снижения размерности.

**Основные задачи**

* Загрузка и исследование транзакционных данных
* Построение матрицы транзакций
* Поиск частых наборов товаров методом Apriori
* Анализ наборов, содержащих товар `turkey`
* Генерация ассоциативных правил
* Поиск правил с максимальным значением lift
* Построение графа ассоциативных зависимостей
* Расчёт метрик центральности HITS (Hubs и Authorities)
* Построение линейной проекции данных методом NMF
* Построение нелинейной проекции методом t-SNE
* Отбор независимых признаков с помощью VarClus

**Продемонстрированные навыки**

* Анализ транзакционных данных
* Market Basket Analysis
* Поиск ассоциативных правил
* Снижение размерности данных
* Визуализация многомерных данных
* Отбор признаков

**Используемые инструменты**

`Pandas` `NumPy` `MLxtend` `Scikit-learn` `NetworkX` `Matplotlib` `Seaborn`

## 💰 Прогнозирование числового отклика. Сравнение линейных и нелинейных подходов

**Описание**

Проект посвящён построению моделей машинного обучения для прогнозирования суммы пожертвования на основе информации о пользователях, ранее совершивших пожертвование. Выполняется сравнение линейных и нелинейных методов прогнозирования.

**Основные задачи**

* Формирование holdout-выборки со стратификацией по отклику
* Анализ распределения целевой переменной
* Обработка пропущенных значений
* Создание индикаторов наличия пропусков
* Отбор признаков методом ForwardOLS
* Подбор оптимальной сложности модели по CV-MSE
* Анализ траекторий коэффициентов линейной модели
* Бутстреп-оценка устойчивости модели
* Оценка распределения свободного члена модели
* Сравнение ошибок CV, OOB и holdout
* Построение многослойного перцептрона (MLP)
* Подбор гиперпараметров нейронной сети
* Визуализация результатов перебора параметров
* Сравнение линейных и нелинейных подходов

**Продемонстрированные навыки**

* Регрессионный анализ
* Отбор признаков
* Кросс-валидация
* Bootstrap-анализ
* Работа с пропущенными значениями
* Настройка гиперпараметров
* Построение нейронных сетей
* Сравнение моделей машинного обучения

**Используемые инструменты**

`Pandas` `NumPy` `Scikit-learn` `Matplotlib` `Seaborn`
